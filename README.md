# FarmFresh – Farm Produce Marketplace

A beginner-friendly Internet Programming project built with HTML, CSS and JavaScript.

## How to run
1. Download and extract `FarmFresh.zip`.
2. Open the `FarmFresh` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet access is needed for the Google Fonts and remote produce photographs. The main functionality works locally.

## Features
- Browse sample agricultural produce listings.
- Search by crop, farmer or location.
- Filter by product category and sort by price.
- Add a new farmer produce listing.
- Send a buyer request for a selected quantity.
- Accept, reject or reset a request status.
- Save listings and requests in browser LocalStorage.
- Responsive layout for mobile and desktop.

## Important project limitation
This is a front-end demonstration. LocalStorage saves data in the current browser only. It does not synchronize information between separate users or devices. A real multi-user marketplace needs a shared backend/database and proper authentication.

## Files
- `index.html` – page structure and forms
- `style.css` – layout, colours and responsive styling
- `script.js` – search, filters, listings, requests and LocalStorage

## Suggested viva preparation
- HTML: semantic elements, forms, labels, input types, buttons and sections.
- CSS: class selectors, flexbox, grid, media queries, hover states and responsive design.
- JavaScript: variables, arrays, objects, functions, event listeners, DOM methods, conditions, loops and LocalStorage.
- Explain the flow: farmer publishes a listing → buyer searches → buyer requests quantity → farmer updates request status.

## Team contribution idea for three members
1. HTML structure and forms.
2. CSS styling and responsive layout.
3. JavaScript functionality and testing.

All team members should understand the complete project and be able to explain the code.
